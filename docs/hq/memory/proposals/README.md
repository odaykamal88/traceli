# Memory proposal inbox

Proposal → Librarian source/conflict/privacy review → Supervisor exact-diff approval → canonical promotion event. A proposal never changes canonical company truth merely by existing.

Required proposal fields: ID/version, target scope, source/job references, proposed diff, fact/inference/decision label, confidence rationale, conflicts, classification, author/time, valid-from/review-after, reviewer, approval reference, promotion status and supersedes pointer. Rejected proposals remain in history with reasons.
